# Как участвовать

Спасибо, что заглянули! Ошибки, идеи и исправления принимаются через [Issues](../../issues) и Pull Requests.

## Нашли ошибку

Откройте задачу и опишите: что делали, что ожидали, что получилось; версию Таверны (в окне сервера или в справке),
систему и браузер. Если ошибка в листе персонажа — назовите лист. Уязвимость — не в общий список задач, а как
написано в [SECURITY.md](SECURITY.md).

## Запустить у себя

Нужен Node.js 22.13 или новее (база — встроенный модуль `node:sqlite`, нативных зависимостей нет).

```bash
npm ci
npm run build        # сайт → dist/
npm run dev          # сервер на http://localhost:3000 с перезапуском при изменениях
npm run dev:client   # или сайт с горячей перезагрузкой на http://localhost:5173 (обращается к серверу на 3000)
```

Данные разработки лежат в `./data` (переменная `DATA_DIR`), настройки — в `.env` (образец — `.env.example`).

## Тесты

```bash
npm test                                  # модульные тесты (node --test)
REGISTER_RATE_LIMIT=1000 npm start &      # e2e-тестам нужен сервер с высоким лимитом регистраций
CHROME=/путь/к/chromium node tests/e2e/run-all.mjs        # все наборы e2e
CHROME=/путь/к/chromium node tests/e2e/run-all.mjs smoke  # один набор
```

e2e-тесты управляют браузером через `playwright-core`. Подойдёт любой Chromium или Chrome — путь в переменной `CHROME`
(или скачайте его командой `npx playwright-core install chromium`). Наборы `desktop` и `vps` проверяют собранную программу
одним файлом, `vps` дополнительно требует `pebble` — тестовый центр сертификации Let's Encrypt.

## Собрать программу

```bash
npm run build:exe    # Windows x64, Linux x64 и ARM64 → release/
```

Сборка идёт на Linux или в WSL; для установщика и файла обновления Windows нужен NSIS (`apt install nsis`).
Выпуски на GitHub собираются сами: достаточно поднять версию в `package.json`, описать её в `CHANGELOG.md`
и отправить тег `vX.Y.Z` — дальше работает [GitHub Actions](.github/workflows/release.yml).

## Как устроен код

- `server/` — Express, Socket.IO и SQLite; состояние стола в памяти с записью в базу.
- `client/` — Preact и Vite; доска, окна, панели, листы персонажей.
- `shared/` — общий код сервера и браузера: кубики, атрибуты, эффекты, ловушки, бестиарий.
- `desktop/` — программа одним файлом: запуск, служба, сертификаты, установщик (NSIS).
- `sheets/` — встроенные листы персонажей (как в репозитории Roll20), `scripts/` — сборка и вспомогательные скрипты.

Комментарии и тексты интерфейса пишутся по-русски — простыми словами, как для игрока, а не для программиста.
Отступ — два пробела, одинарные кавычки, точка с запятой в конце. Новое поведение — вместе с тестом: модульным
в `tests/*.test.mjs` или шагом e2e в `tests/e2e/`.

Присылая изменения, вы соглашаетесь, что они распространяются под лицензией проекта — GNU AGPL-3.0.
