# Безопасность

Таверну часто ставят на сервер в интернете, поэтому сообщения об уязвимостях очень важны.

**Как сообщить.** Не открывайте общедоступную задачу — напишите закрыто: вкладка **Security** этого репозитория →
**Report a vulnerability**. Опишите, что можно сделать и как это повторить; если есть — версию Таверны и пример запроса.
Ответ придёт в той же переписке; когда исправление выйдет, в описании выпуска будет сказано, что закрыто и кого поблагодарить
(если вы не против).

**Какие версии исправляются.** Последний выпуск. Обновиться просто: на Windows — файлом `Taverna-<версия>-update.exe`,
на сервере — `sudo ./taverna-linux-x64 install` из новой версии; данные при этом сохраняются.

**Что уже сделано.** Пароли хранятся хешами (scrypt), вход — через cookie с флагом HttpOnly и защитой от CSRF,
строгая политика CSP, листы персонажей и их скрипты работают в изолированных iframe и Web Worker, загрузки проверяются
по содержимому, а не по имени, ссылки на чужие сайты сервер скачивает только из открытого интернета.
